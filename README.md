# GULAG

**GULAG** (Graphical User Interface for Layout, Analysis and Gizmos) — настольный редактор робототехнических комплексов (РТК) для проекта **USSR**. Его цель — дать инженеру рабочее место для компоновки сцены, запуска моделирования и анализа движений манипулятора.

## Место в проекте USSR

USSR объединяет инструменты моделирования, планирования движений и обучения роботов. **COMRaDE** — вычислительное ядро на C++ для кинематики, динамики и контактов. **KGB** предоставляет Python-интерфейс к ядру для сценариев и пакетных расчётов. По архитектуре проекта **GULAG** будет работать с KGB в одном Python-процессе, чтобы действия в графическом редакторе и в сценариях вызывали одни и те же операции.

Текущая версия запускается самостоятельно. В ней работают 3D-навигация, дерево сцены с папками, настройка панелей и тем. **Scope** пока создаёт область графика, **Console** ведёт журнал ввода. Загрузка роботов из каталога, работа с файлами сцен и запуск симуляции запланированы на этап интеграции с KGB и COMRaDE.

## Требования к сборке и запуску

| Компонент | Для чего нужен |
|---|---|
| Git | Скачать исходники из репозитория. |
| CPython 3.12.x, 64-разрядный | Версия интерпретатора зафиксирована в `.python-version` и `pyproject.toml`. Её можно установить через uv. |
| uv | Создать окружение, установить версии зависимостей из `uv.lock` и собрать wheel. Сборка проверена с uv 0.13.6 на Windows x64. |
| Графическая сессия и драйвер с поддержкой WebGPU через wgpu-native | Для запуска 3D-окна. На Windows используется Vulkan или DirectX 12, на Linux — Vulkan. [Требования графического бэкенда](https://wgpu-py.readthedocs.io/en/stable/start.html#platform-requirements) |

Интерфейс использует Qt 6 (PySide6 Essentials), отрисовка — pygfx, wgpu и rendercanvas. Эти библиотеки устанавливает uv. Для первой установки нужен доступ к источникам Python и пакетов. Для сборки самого GULAG достаточно Python и uv с бэкендом `uv_build`, указанным в `pyproject.toml`.

## Скачать и запустить

1. Установите Git и uv. На Windows с WinGet выполните команды в PowerShell, затем откройте новый терминал. Для других систем доступны [инструкции Git](https://git-scm.com/downloads) и [инструкции uv](https://docs.astral.sh/uv/getting-started/installation/).

   ```powershell
   winget install --id Git.Git -e
   winget install --id astral-sh.uv -e
   ```

2. Скачайте репозиторий в выбранную рабочую папку и перейдите в каталог проекта.

   ```sh
   git clone https://github.com/alex010501/GULAG.git
   cd GULAG
   ```

3. Подготовьте интерпретатор и зависимости. Команда `sync` создаст локальное окружение `.venv`.

   ```sh
   uv python install 3.12
   uv sync --locked
   ```

4. Запустите редактор из корня репозитория. Откроется окно **USSR** с 3D-сценой. Эта же команда подходит для последующих запусков.

   ```sh
   uv run --locked gulag
   ```

## Проверка и сборка пакета

Из корня репозитория запустите тесты интерфейса и соберите установочный пакет Python.

```sh
uv run --locked pytest -q
uv build --wheel
```

Wheel появится в каталоге `dist/`. Чтобы установить его на другой машине, в активном окружении Python 3.12 выполните `uv pip install <путь-к-файлу.whl>`, затем запустите `gulag`.

## Рабочее окно

На верхней ленте **Workspace** содержит команды документа и сцены, а **Simulation** задаёт частоту и длительность симуляции.

Слева от 3D-вида открыта **Library**. Пока в ней отображается заглушка. В дальнейшем каталог будет брать роботов и другие объекты РТК для расстановки на сцене из системной директории приложения. Справа расположены **Scene Tree** и вкладки **Properties** и **Plots**. Чтобы добавить график, нажмите **Workspace → Plots → Scope** или **Add Scope** на вкладке **Plots**. **Console** под сценой записывает введённые строки в журнал.

Перетащите панель за заголовок к краю рабочей области, чтобы закрепить её там, или поверх другой панели, чтобы объединить их во вкладки. Двойной щелчок по заголовку отсоединяет панель в отдельное окно или возвращает её обратно. Разделители меняют размеры панелей. При закрытии приложения раскладка сохраняется. Через **Workspace → Panels** можно открыть скрытую панель, а через **Restore default layout** — вернуть исходное расположение.

В **Settings → Appearance → Theme** выберите **Light**, **Dark** или **System** и нажмите **OK**. Тема сразу применяется к окну, ViewCube и 3D-сцене и сохраняется между запусками. По умолчанию **System** следует оформлению ОС. Если система не сообщает цветовую схему, редактор использует светлую тему.

## Навигация в 3D

| Действие | Mouse | Touchpad |
|---|---|---|
| Перемещение | Удерживать среднюю кнопку и двигать мышь | Shift и перетаскивание правой кнопкой |
| Вращение | Перетаскивание правой кнопкой | Перетаскивание правой кнопкой |
| Масштаб | Колесо | Жест прокрутки |

Клик правой кнопкой открывает меню сцены. Перетаскивание левой рисует синюю рамку слева направо или зелёную пунктирную справа налево. Рамка служит для предпросмотра и исчезает при отпускании кнопки или нажатии Esc.

В **Settings** можно выбрать пресет или создать копию через **Create preset…**. Для своей копии задайте жест для каждого действия и нажмите **OK**. Программа сохраняет привязки и выбранный пресет в настройках пользователя.

Плоский ViewCube находится в нижнем правом углу 3D-вида. Щелчок по грани, полосе ребра или точке на стыке трёх граней поворачивает камеру в выбранном направлении. При наведении соответствующая область подсвечивается бирюзовым. **Top** и **Bottom** переключают полусферу и ставят камеру перпендикулярно плоскости XY.

Кнопка с контурным кубом на левой панели 3D-вида переключает **Orthographic** и **Perspective**. Название проекции видно над сценой. При переключении сохраняются направление взгляда, центр вращения и масштаб на глубине этого центра. Кнопка с домиком возвращает исходный ракурс в выбранной проекции.

## Ресурсы интерфейса

Текст окна **About / Help** хранится в [resources/runtime/gulag/about.html](resources/runtime/gulag/about.html). После установки wheel это отдельный файл `gulag/about.html` в каталоге пакетов Python. Следующая команда выводит его точный путь для активного окружения.

```sh
python -c "from gulag.window import ABOUT_FILE; print(ABOUT_FILE)"
```

Сохраните HTML в UTF-8 и заново откройте **About / Help**. Окно перечитывает файл при каждом открытии. Метки `${pan}`, `${orbit}` и `${zoom}` подставляют жесты из активного профиля навигации.

Форма рабочего окна находится в `src/gulag/workspace.ui` и открывается в Qt Designer. После изменения исходных иконок или шрифта пересоберите пакет ресурсов Qt следующей командой.

```powershell
uv run pyside6-rcc --binary resources/workbench.qrc -o src/gulag/workbench.rcc
```
